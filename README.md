
## Setup

when icluding this folder as a submodule, make sure to include these variables in the root `.env` file
```env
DB_USER=...
DB_NAME=...
DB_PASS=...
```

## Running the script

make sure you change the working directory to `/offer-extraction` and run
```bash
npm run start <browser>
```
where browser can be `chrome` or `firefox`.
